# Where2Buyy 🛒

Where2Buyy is a responsive and user-friendly frontend built with React and Vite. It displays top-rated products, top brands, offer banners, and detailed product pages, helping users find the best deals from popular online stores.

---

## 🌟 Features

- 🌙 Light/Dark mode toggle
- 🔍 Product search functionality
- 🛍️ Display of multiple product variants
- 🏷️ Offer banners and promotions
- 🏆 Top-rated and top-branded sections
- 📦 Product detail page with variant filtering
- 📧 Newsletter subscription section
- 📱 Responsive design across all devices

---

## 🚀 Technologies Used

- **React.js** (Functional Components & Hooks)
- **Vite** (Blazing-fast build tool)
- **JavaScript (ES6+)**
- **Tailwind CSS** (Utility-first CSS framework)
- **React Icons**

## 📁 Folder Structure

##  Install Dependencies
npm install

npm run dev
